

# MOEX Portfolio Risk

Проект по анализу недельных котировок акций Московской биржи и построению портфеля минимального риска.

Цель проекта — загрузить исторические данные по нескольким акциям, очистить и объединить их, рассчитать недельные доходности, построить ковариационную матрицу и найти веса портфеля, минимизирующие историческую дисперсию доходности.

## 1. Данные

В проекте используются CSV-файлы с недельными данными по акциям Московской биржи.

Каждый файл соответствует одной акции. Тикер акции извлекается из имени файла. Например:

```text
SBER_weekly.csv
GAZP_weekly.csv
LKOH_weekly.csv
```

В исходных данных используются следующие поля:

| Поле | Описание |
|---|---|
| `datetime` | дата недельной свечи |
| `open` | цена открытия |
| `high` | максимальная цена за неделю |
| `low` | минимальная цена за неделю |
| `close` | цена закрытия |

Для расчётов используется столбец `close`, потому что доходности считаются между ценами закрытия соседних недель.

Исходные CSV-файлы должны лежать в папке:

```text
data/
```

## 2. Методика расчёта

Для каждой акции берётся последовательность недельных цен закрытия.

Недельная доходность рассчитывается по формуле:

```text
r_t = P_t / P_{t-1} - 1
```

где:

- `P_t` — цена закрытия текущей недели;
- `P_{t-1}` — цена закрытия предыдущей недели.

После этого по таблице недельных доходностей строится ковариационная матрица доходностей.

Портфельный риск считается по формуле:

```text
w^T Sigma w
```

где:

- `w` — вектор весов акций в портфеле;
- `Sigma` — ковариационная матрица недельных доходностей.

Оптимизатор решает задачу:

```text
min w^T Sigma w
```

при ограничениях:

```text
sum(w_i) = 1
0 <= w_i <= 1
```

То есть весь капитал распределяется между выбранными акциями, а короткие позиции запрещены.

## 4. Основные модули

### `data_source.py`

Содержит класс `MoexCSVDataSource`.

Он отвечает за поиск CSV-файлов в папке с данными и извлечение тикера из имени файла.

Основные методы:

- `iter_csv_files()` — лениво возвращает пути к CSV-файлам;
- `extract_ticker()` — извлекает тикер из имени файла.

### `processor.py`

Содержит класс `MarketDataProcessor`.

Он отвечает за обработку рыночных данных с помощью `pandas`.

Основные методы:

- `load_price_tables()` — загружает отдельные таблицы цен закрытия;
- `build_close_price_table()` — объединяет цены закрытия разных акций по общим датам;
- `calculate_returns()` — рассчитывает недельные доходности;
- `calculate_covariance_matrix()` — строит ковариационную матрицу доходностей.

### `optimizer.py`

Содержит класс `MinimumVarianceOptimizer`.

Он отвечает за поиск портфеля минимальной дисперсии.

Внутри используется оптимизация функции:

```text
w^T Sigma w
```

с ограничениями на сумму весов и неотрицательность весов.

### `exporter.py`

Содержит класс `ReportExporter`.

Он сохраняет результаты работы проекта в папку `results/`.

### `decorators.py`

Содержит собственный декоратор `execution_time`.

Он измеряет время выполнения выбранных функций проекта.

### `exceptions.py`

Содержит пользовательские исключения проекта.

Например:

- `MarketDataError`;
- `MissingDateError`;
- `EmptyDataError`;
- `PortfolioOptimizationError`.

## 5. Обработка данных в pandas

В проекте выполняются следующие шаги обработки данных:

1. загрузка CSV-файлов с помощью `pandas.read_csv`;
2. выбор нужных столбцов с датой и ценой закрытия;
3. преобразование даты в формат `datetime`;
4. переименование столбца `close` в тикер соответствующей акции;
5. проверка пропущенных дат;
6. установка даты в качестве индекса таблицы;
7. объединение таблиц разных акций по общим датам;
8. сортировка временного ряда по дате;
9. расчёт недельных доходностей через `pct_change`;
10. построение ковариационной матрицы доходностей.

## 6. Потоковая обработка без pandas

В проекте используется ленивый перебор CSV-файлов.

Метод `iter_csv_files()` класса `MoexCSVDataSource` возвращает пути к файлам по одному через `yield`.

Это позволяет не собирать весь список файлов заранее в отдельную структуру данных.

Пример:

```python
def iter_csv_files(self):
    for file_path in iglob(f"{self.data_dir}/*.csv"):
        yield file_path
```

## 8. Пользовательские исключения

В проекте определены пользовательские исключения для обработки ошибок.

Примеры ситуаций:

- отсутствуют CSV-файлы с данными;
- в таблице есть пропуск даты;
- оптимизатор не смог найти допустимое решение;
- сумма весов портфеля не равна единице;
- получены отрицательные веса.

Такие ошибки обрабатываются отдельно от стандартных исключений Python и делают поведение программы более понятным.

## 10. Паттерн проектирования

На текущем этапе основной алгоритм построения портфеля реализован в классе `MinimumVarianceOptimizer`.

Паттерн проектирования Strategy может быть добавлен следующим шагом: для этого можно вынести разные способы построения портфеля в отдельные классы, например:

- `EqualWeightStrategy` — равновзвешенный портфель;
- `MinimumVarianceStrategy` — портфель минимальной дисперсии.

После добавления этих классов внешний код сможет использовать единый метод `build()`, а конкретный способ построения портфеля будет определяться выбранной стратегией.

python main.py

1. найдёт CSV-файлы в папке `data/`;
2. загрузит цены закрытия;

4. рассчитает недельные доходности;
5. построит ковариационную матрицу;
6. найдёт веса портфеля минимальной дисперсии;
7. сохранит результаты в папку `results/`.
